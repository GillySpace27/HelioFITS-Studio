# Credits and citing

HelioFITS Studio is a fork of JHelioviewer, the open-source solar image browser from the ESA/NASA
Helioviewer Project
([github.com/Helioviewer-Project/JHelioviewer-SWHV](https://github.com/Helioviewer-Project/JHelioviewer-SWHV)),
and is licensed under MPL 2.0, as JHelioviewer is. The tools described here are built on it. Several
of them (the PUNCH layer, the RHEF filter, the Helioradial projections and the grid controls) have been
taken into JHelioviewer's own development line, and others were submitted there as pull requests.
