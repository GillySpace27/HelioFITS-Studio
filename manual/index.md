# HelioFITS Studio user manual

HelioFITS Studio is a solar image browser built on JHelioviewer, the open-source viewer from the
ESA/NASA Helioviewer Project. It adds tools for coronal research: the Sun-centred Helioradial
projection and its unrolled form, which give the outer corona the room an ordinary view never
gives it; PUNCH, PROBA-3/ASPIICS and native LASCO data; the RHEF radial filter; CME tracking; a
3-D point cloud layer; synoptic maps wrapped onto the globe; a colour-table legend; and a FITS
library shared with HelioFITS Core.

This manual is for version {{ release }}. It is built from the same files the app reads
(its menus, tours, tips and changelog), so where it lists a command or a tour step it says what the
app says. HelioFITS Studio is an unofficial fork, maintained at
[github.com/GillySpace27/HelioFITS-Studio](https://github.com/GillySpace27/HelioFITS-Studio).
