HelioFITS Studio for Windows
============================

To start it, double-click HFStudio.exe in this folder.

If you are looking at this inside the zip, extract it first: close this,
right-click the zip, choose Extract All, then open the HFStudio folder it makes.
The program cannot start from inside the zip.

Nothing to install, and no administrator rights needed. Java is included.
The folder can live anywhere you can write, such as Downloads, Documents or a
USB stick, and you can move it later. The program keeps its settings and saved
sessions in %USERPROFILE%\HFStudio and its cache in %TEMP%\HFStudio; it never
writes into this folder.

The first time, Windows may say it "protected your PC", because the program is
not code-signed yet. Choose More info, then Run anyway. You only do this once.

To remove it, delete this folder (and %USERPROFILE%\HFStudio if you also want
your settings and sessions gone).

Problems: https://github.com/GillySpace27/HelioFITS-Studio/issues
or gilly@nwra.com. Please say what Windows version and what happened.
